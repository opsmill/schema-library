---
title: NetBox Cooling
---

Cooling sources and cooling feeds: the Cooling section of the NetBox navigation menu, mapped from the NetBox 4.7 dcim tables. Cooling intakes and outflows are device components in netbox/netbox_devices.

## Details

- **Dependencies:**
    - [netbox/netbox_organization](netbox_organization)
    - [netbox/netbox_devices](netbox_devices)
    - [netbox/netbox_racks](netbox_racks)

## Use cases

This extension covers:
- Import NetBox cooling sources, such as chillers, and the cooling feeds that supply each rack.

Out of scope, and what to reach for instead:
- Decimal cooling capacities and flow rates. They are stored as whole numbers in watts and liters per minute, because Infrahub has no decimal attribute kind.

## Nodes

### CoolingSource

- **Label:** Cooling Source
- **Description:** A facility-level source of cooling, such as a chiller, cooling tower or dry cooler. It is the upstream origin of cooling feeds.
- **Namespace:** Netbox
- **Icon:** mdi:snowflake
- **Human Friendly ID:** site__name__value, name__value
- **Inherit From:** NetboxGeneric, NetboxContactAssignable

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| name |  | Text | False |  |  |
| type |  | Dropdown | False |  | chiller, cooling-tower, dry-cooler, crac, crah |
| status |  | Dropdown | False | active | offline, active, planned, failed |
| fluid_type |  | Dropdown | True |  | water, water-glycol, dielectric, refrigerant |
| cooling_capacity_watts | NetBox stores a decimal value in kilowatts. Converted to watts here. | Number | True |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| site | NetboxSite | False | one | Attribute |
| location | NetboxLocation | True | one | Attribute |
| cooling_feeds | NetboxCoolingFeed | True | many | Generic |

### CoolingFeed

- **Label:** Cooling Feed
- **Description:** A coolant loop delivered from a cooling source to a rack or a coolant distribution unit (CDU).
- **Namespace:** Netbox
- **Icon:** mdi:pipe
- **Uniqueness Constraints:**
    - cooling_source, name__value
- **Inherit From:** NetboxGeneric, NetboxTenantAssignable

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| name |  | Text | False |  |  |
| status |  | Dropdown | False | active | offline, active, planned, failed |
| cooling_capacity_watts | NetBox stores a decimal value in kilowatts. Converted to watts here. | Number | True |  |  |
| max_flow_liters_per_minute | NetBox stores a decimal flow rate in L/min, m3/h or gal/min. Converted to liters per minute here. | Number | True |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| cooling_source | NetboxCoolingSource | False | one | Attribute |
| rack | NetboxRack | True | one | Attribute |
