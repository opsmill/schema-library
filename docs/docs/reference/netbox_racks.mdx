---
title: NetBox Racks
---

Racks, rack reservations, rack groups, rack roles and rack types: the Racks section of the NetBox navigation menu, mapped from the NetBox 4.7 dcim tables. Adds the rack, position and rack face fields to devices.

## Details

- **Dependencies:**
    - [netbox/netbox_organization](netbox_organization)
    - [netbox/netbox_devices](netbox_devices)

## Use cases

This extension covers:
- Import NetBox racks with their rack types, roles and groups, and the rack, position and face of each device.
- Reserve rack units for future use.

Out of scope, and what to reach for instead:
- Half rack units, such as a 0.5U rack position. Positions and heights are whole rack units.
- Decimal weights and cooling capacities. They are stored as whole numbers in grams and watts, because Infrahub has no decimal attribute kind.
- Unique rack names. NetBox makes them unique within a location, which an Infrahub uniqueness constraint cannot include.
- NetBox users as the owners of rack reservations. Reservations refer to Infrahub accounts.

## Nodes

### RackGroup

- **Label:** Rack Group
- **Description:** Groups racks by physical placement, such as a row or an aisle, next to their location. Rack groups cannot be nested.
- **Namespace:** Netbox
- **Icon:** mdi:view-column
- **Human Friendly ID:** name__value
- **Inherit From:** NetboxGeneric, NetboxVLANGroupScope

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| name |  | Text | False |  |  |
| slug | URL-friendly identifier that NetBox derives from the name. | Text | True |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| racks | NetboxRack | True | many | Generic |

### RackReservation

- **Label:** Rack Reservation
- **Description:** Reserves specific units within a rack for future use. A reservation cannot span multiple racks.
- **Namespace:** Netbox
- **Icon:** mdi:calendar-lock
- **Inherit From:** NetboxGeneric, NetboxTenantAssignable

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| units | Rack units that are reserved, for example [1, 2, 3]. | List | False |  |  |
| status |  | Dropdown | False | active | pending, active, stale |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| rack | NetboxRack | False | one | Parent |
| user | CoreAccount | True | one | Attribute |
