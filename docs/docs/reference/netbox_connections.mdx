---
title: NetBox Connections
---

Cables and cable bundles: the Connections section of the NetBox navigation menu, mapped from the NetBox 4.7 dcim tables. Adds the cable, cable end and connector fields to the interfaces, ports, power feeds and circuit terminations that a cable can connect to.

## Details

- **Dependencies:**
    - [netbox/netbox_organization](netbox_organization)
    - [netbox/netbox_devices](netbox_devices)

## Use cases

This extension covers:
- Import NetBox cables with the objects at each end, and the cable end (A or B) of each object.
- Group cables that share a route or a purpose into cable bundles.

Out of scope, and what to reach for instead:
- Cable path tracing, and the interface, console and power connection lists that NetBox computes from cable paths.
- Decimal cable lengths. They are stored as whole numbers in centimeters, because Infrahub has no decimal attribute kind.
- Wireless links (wireless).

## Nodes

### Cable

- **Description:** A direct physical connection between two sets of endpoints, A and B, for example two interfaces.
- **Namespace:** Netbox
- **Icon:** mdi:cable-data
- **Inherit From:** NetboxGeneric, NetboxTenantAssignable

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| physical_label | Label used to identify the cable. The NetBox field is called label. | Text | True |  |  |
| type |  | Dropdown | True |  | cat3, cat5, cat5e, cat6, cat6a, cat7, cat7a, cat8, mrj21-trunk, dac-active, dac-passive, coaxial, rg-6, rg-8, rg-11, rg-59, rg-62, rg-213, lmr-100, lmr-200, lmr-400, mmf, mmf-om1, mmf-om2, mmf-om3, mmf-om4, mmf-om5, smf, smf-os1, smf-os2, aoc, power, usb |
| status |  | Dropdown | False | connected | connected, planned, decommissioning |
| profile | Maps the terminations at each end to connectors and positions, for example for breakout cables. | Dropdown | True |  | single-1c1p, single-1c2p, single-1c4p, single-1c6p, single-1c8p, single-1c12p, single-1c16p, trunk-2c1p, trunk-2c2p, trunk-2c4p, trunk-2c4p-shuffle, trunk-2c6p, trunk-2c8p, trunk-2c12p, trunk-4c1p, trunk-4c2p, trunk-4c4p, trunk-4c4p-shuffle, trunk-4c6p, trunk-4c8p, trunk-8c4p, breakout-1c2p-2c1p, breakout-1c4p-4c1p, breakout-1c6p-6c1p, breakout-1c8p-8c1p, breakout-2c4p-8c1p-shuffle |
| color | Color as a hex code, for example #aa1409. | Color | True |  |  |
| length_centimeters | NetBox stores a decimal length in km, m, cm, mi, ft or in. Converted to centimeters here. | Number | True |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| bundle | NetboxCableBundle | True | one | Attribute |
| terminations | NetboxCabledObject | True | many | Generic |

### CableBundle

- **Label:** Cable Bundle
- **Description:** A logical grouping of cables that share a purpose, route or physical grouping, such as a conduit, trunk or wiring harness.
- **Namespace:** Netbox
- **Icon:** mdi:cable-data
- **Human Friendly ID:** name__value
- **Inherit From:** NetboxGeneric

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| name |  | Text | False |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| cables | NetboxCable | True | many | Generic |

## Extensions

:::note

In this context "extensions" refer to modifications or additions to the existing schema, such as adding new attributes, relationships, or other schema elements.

:::

### NetboxCabledObject

#### Attributes

| name | description | kind | optional | default_value | choices |
| ---- | ----------- | ---- | -------- | ------------- | ------- |
| cable_end | End of the cable that connects to this object. | Dropdown | True |  | A, B |
| cable_connector | Connector of the cable profile that this object uses. | Number | True |  |  |
| cable_positions | Positions of the cable profile connector that this object uses. | List | True |  |  |

#### Relationships

| name | peer | optional | cardinality | kind |
| ---- | ---- | -------- | ----------- | ---- |
| cable | NetboxCable | True | one | Attribute |
