The schema load test in CI now runs through `infrahub-testcontainers` against a pinned Infrahub version (`infrahub-testcontainers` in the `integration` dependency group) instead of the latest Infrahub image. Each non-experimental schema loads in its own test, in dependency order, and a failure names the schema and shows the `infrahubctl` output. A new workflow, `update-infrahub.yml`, opens a pull request for the SA team when Infrahub publishes a release. Run the test locally with `uv sync --group dev --group integration && uv run pytest tests/integration`. Unit tests moved to `tests/unit`, and `.github/CODEOWNERS` requests review from `@opsmill/sa`.
